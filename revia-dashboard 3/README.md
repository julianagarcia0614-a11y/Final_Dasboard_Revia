# Reviá by La Font — Dashboard Digital

Dashboard de rendimiento digital para Reviá Capilar (Bogotá).
Cubre Meta Ads, Meta Orgánico, Google My Business y CRM Setter Bot.
Período: Enero – Abril 2026.

## Deploy en Vercel

1. Importa este repo en [vercel.com](https://vercel.com)
2. Framework: **Other** (static site)
3. Root directory: `/`
4. Click **Deploy** — listo.

## Stack

- HTML + CSS + JavaScript vanilla
- Chart.js 4.4.1 (CDN)
- Google Fonts: Syne + DM Sans
- Sin dependencias de build
